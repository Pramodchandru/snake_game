# Pramod: Island Survival 🏝️

A top-down 2D island survival game built with HTML5 Canvas and JavaScript.

## 🎮 Play Live
👉 **[Play Island Survival Live](https://pramodchandru.github.io/snake_game/)**

---

## 🕹️ Game Controls

| Action | Controls |
| :--- | :--- |
| **Move** | `Arrow Keys` or `W`, `A`, `S`, `D` |
| **Attack / Swing** | `Spacebar` or `Left Click` |
| **Interact / Gather** | `E` (Chop trees, mine rocks, pick berries, drink from lakes) |
| **Eat Food** | `F` (Eat cooked meat or berries) |
| **Craft Campfire** | `1` (Cook meat, stay warm, keep zombies away) |
| **Craft Spear** | `2` (Increased damage & range) |
| **Pause / Resume** | `P` or `Esc` |
| **Start / Restart** | `Enter` or `Click` |

---

## 🌴 Survival Guide & Features
- **Day & Night Cycle:** Daylight allows safe exploration. Night brings danger—craft campfires and watch out for zombies!
- **Vital Stats:** Manage your Health, Hunger, Thirst, and Stamina.
- **Resource Gathering:** Chop trees for wood, mine boulders for stone, and pick bushes for berries.
- **Hunting & Cooking:** Hunt rabbits for raw meat and cook them at campfires for maximum nutrition.
- **Goal:** Survive for 5 days on the island!

## 🚀 Local Setup
To run the game locally:
1. Clone this repository:
   ```bash
   git clone https://github.com/Pramodchandru/snake_game.git
   ```
2. Open `index.html` in your favorite web browser.
